## 0. 前提：Mac 版不是自包含的

先把期望放对。Mac 上**做不出**一个拷给别人就能用的安装包：

- KataGo 官方 61 个 release 里一个 mac 资源都没有 → 引擎必须在目标机上
  `brew install katago` **现场编译**（十几分钟到半小时）
- Python 侧零第三方依赖，所以不用打包 Python

结论：产物是一个 **`.app` 壳**，内部软链到项目目录，引擎和 Python 都来自 brew。
**别人装了也用不了**，除非他也 brew 了一遍。所以这次的目标不是发布，是**验证 + 取数**。

## 1. 拉代码

```bash
git clone https://github.com/armandyu2000-cyber/weiqi-web.git
cd weiqi-web
```

只有 290KB —— 引擎、模型、自然音（约 180MB）都不在仓库里，第 3 步会现下。

> `macos/` 下两个脚本的可执行位在仓库里是好的（`100755`），不用 `chmod`。

## 2. 装依赖

```bash
brew install katago python      # katago 要现场编译，慢
katago version                  # 应该报 1.18.2 左右
python3 -V
```

> 注意 `katago version` **不显示后端**。「brew 编出来的走 Metal / OpenCL / 纯 CPU Eigen」
> 是这次要实测的头号问题，查法见第 5 步。

## 3. 执行前的配置改动

**代码层面必改项：0 个。** `katago.ENGINE` 按平台自动挑（`Darwin` → `"macos"`），
`engine_paths()` 会自动退回 PATH 找 brew 的 katago。别为了让 AI 有活干而去改它。

只有两种情况需要动手，都是**先跑、出问题再改**：

| 症状 | 改哪里 | 怎么改 |
|---|---|---|
| `setup.py` 报「两条线路都没下成」 | 环境变量 | `export GO_PROXY=http://<你的代理>`。`setup.py:29` 默认写的是 `http://127.0.0.1:7892`（Windows 那台机器的本地代理），Mac 上不存在。**直连能成的话这行用不到** —— 代码是先直连、失败才走代理。 |
| 段位档每手十几秒 | `katago.search_params()` | 削段位那行的 `maxVisits`（现在 `100 + (n-1)*20`）。**先量再改** —— 它真改棋，1 段搜 25 / 9 段搜 135、第一选点都不同。 |

改完 `GO_PROXY` 那个是环境变量，不用改文件；`maxVisits` 那个要是真改了，属于产品行为
变更，得同步 `README.md` 里那张实测表。

## 4. 跑起来

```bash
python3 setup.py                       # 下约 180MB，可重复执行
./macos/install_macos.command          # 装到 ~/Applications/围棋.app
```

然后去**应用程序**文件夹双击 `围棋`。第一次启动要十几秒（引擎在加载 120MB 的神经网络）。

存档 / 启动日志：`~/Library/Application Support/Go/`

> 双击被 Gatekeeper 拦就 `xattr -dr com.apple.quarantine ~/Applications/围棋.app`，
> 详见 `README-macOS.md` 的「出问题」一节。

### ★ 查后端

`katago version` 不显示后端，得让它启动一次、读 stderr 的横幅：

```bash
echo quit | katago gtp \
  -config vendor/engines/macos/gtp_human5k_example.cfg \
  -model vendor/models/g170-b15c192-s497233664-d149638345.bin.gz 2>&1 | head -25
```

找 `Using ... backend` 那一行。**这一步决定这个程序在 Mac 上能不能用**：

| 后端 | 判断 |
|---|---|
| Metal / OpenCL | 好，GPU 在跑 |
| Eigen（纯 CPU） | **每手十几秒，基本不可用** → 回来削 `maxVisits` 或换小模型 |

### ★ 量每手耗时

```bash
python3 probe_delay.py
```

一次跑完两段：① 验证人工延迟没进搜索（应该和 Windows 上结论一致），
② 给出 9k / 1k / 1d / 9d 各档位的每手墙钟。**第二段就是要的数据。**
